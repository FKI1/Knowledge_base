# База знаний

Закрытый веб-сайт с авторизацией на Python (FastAPI + PostgreSQL). Страница входа оформлена как
подвесная лампа: нужно потянуть за шнурок, чтобы включить свет и увидеть форму входа.

> **Статус: ранняя версия.** Готова авторизация. Самой базы знаний (статьи, разделы, поиск) пока нет:
> после входа открывается страница-заглушка с приветствием и кнопкой «Выйти».

## Что уже есть

- Вход по email и паролю, выход, сессии в базе данных.
- Регистрация с никнеймом и подтверждением email.
- Восстановление пароля по ссылке из письма.
- Защита: пароли в Argon2id, лимиты попыток и блокировка аккаунта, проверка Origin (CSRF), cookie `HttpOnly` + `SameSite=Strict`,
  заголовки безопасности (CSP и др.), одинаковые ответы, не раскрывающие, зарегистрирован ли email.
- Страница входа: лампа с перетягиваемым шнурком, адаптивная вёрстка, управление с клавиатуры, показ пароля.

## Структура

```
app/main.py          сервер: маршруты, база, письма
pages/login.html     страница входа (вход / регистрация / восстановление)
pages/kb.html        закрытая страница после входа (пока заглушка)
static/login.css     оформление
static/login.js      поведение страницы входа
static/kb.js         поведение закрытой страницы
create_user.py       создание пользователя из консоли
docker-compose.yml   PostgreSQL
requirements.txt     зависимости Python
.env.example         пример настроек
```

## Запуск (локально)

Нужны Python 3.12+ и Docker.

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env          # затем впишите свой пароль в DB_PASSWORD и DATABASE_URL
docker compose up -d          # запустить PostgreSQL

uvicorn app.main:app --reload  # таблицы создадутся при первом запуске
```

Сайт: http://localhost:8000

Создать первого пользователя (без подтверждения почты):

```bash
python create_user.py
```

Без настройки SMTP письма (подтверждение email, сброс пароля) печатаются в консоль, где запущен uvicorn: оттуда можно взять ссылку.

## Настройки (`.env`)

| Переменная | Назначение |
|---|---|
| `DATABASE_URL` | подключение к PostgreSQL (обязательно) |
| `DB_PASSWORD` | пароль для контейнера PostgreSQL |
| `BASE_URL` | адрес сайта в браузере; от него зависят проверка Origin и ссылки в письмах |
| `COOKIE_SECURE` | `true` только по HTTPS (на боевом сервере обязательно), `false` для локальной работы |
| `SESSION_HOURS` | срок жизни сессии |
| `REGISTRATION_OPEN` | `false` закрывает самостоятельную регистрацию |
| `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD`, `SMTP_FROM` | отправка почты |

## Перед выкладкой на сервер

- HTTPS и `COOKIE_SECURE=true`, верный `BASE_URL`.
- Если сайт за прокси (nginx и т. п.): запускать uvicorn с `--proxy-headers`, иначе лимит по IP считается по адресу прокси.
- Настроить SMTP и решить, нужна ли открытая регистрация (`REGISTRATION_OPEN`).
- Периодически чистить служебные таблицы `login_attempts` и `sessions` (сейчас чистятся только при запуске).
- Автотестов пока нет: основные сценарии (вход, регистрация, сброс пароля, блокировка) стоит пройти вручную.
